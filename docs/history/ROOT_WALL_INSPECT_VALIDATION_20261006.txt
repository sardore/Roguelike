만루 V31 해련 뿌리 바위벽 조사 설명 수정 (2026-10-06)
기준: 최신 전달 V30 실행본/소스. V30 먹물 피해 집계·표시와 이전 수정 포함.

재현
- 일반 테마 전장에서 실제 해련 바위벽을 만들고 조사하면 용궁 분기 제한으로 바위 설명이 빠짐. 공통 지형 이름에는 등록되지 않아 지형이라는 이름과 기본 구조물 문구가 나옴. 지형 도감에도 설명이 없음.
- 용궁 테마에서는 빈 바위 칸 설명은 존재하지만, 바위에 몬스터/시체가 겹치면 몬스터/시체 조사가 먼저 열림. 일반 테마도 동일.
- V30 PC·모바일 각각15개 기준본 검사로 위 현상을 확인.

수정
- 원본 palaceInspect105에서 바위벽 정의를 용궁 위치 제한보다 먼저 반환. 바위 자체의 생성 위치와 무관하게 설명을 제공.
- 공통 terrainName에 해련 바위벽 이름 등록. TERRAIN986 지형 도감은 기존 원본 정의를 직접 읽어 같은 설명을 사용. 별도 중복 설명·wrapper 없음.
- 지형 정의의 inspectPriority57 값을 원본 조사·infoAt·terrainInfo986 경로가 읽도록 함. 실제 바위벽 칸은 겹친 몬스터·시체·새 예고·증기보다 먼저 바위 설명을 제공. 지형 정의가 우선순위를 결정하며, 몬스터별 예외나 조사 후 사후 보정 없음.
- 설명: 실제로 솟은 칸의 적 기절1턴, 다음 행동 뒤 붕괴, 주변3×3 대지 피해, 기본 피해 해련 공격력×1.4, 다중 바위 중첩. 이동/시야/투사체/점멸 차단.
- 미탐사 칸 보호·짧은 터치 조사 금지·기존660ms 길게 누르기 유지. 바위 붕괴 뒤에는 원래 조사 경로 사용.
- 바위 생성/기절/수명/피해/외형/전장 입력 원본 함수는 바이트 동일. 신규 최상위 함수·wrapper·monkey patch·함수 재대입 없음.

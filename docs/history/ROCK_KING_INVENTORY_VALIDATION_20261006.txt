재현
- 기존 V28, PC·모바일 각각8검사. 빙판에 바위 생성이 실패한 뒤에도 기절이 발생. 벤치·화단·정원 나무 위 바위는 임시 지형 기록이 지워졌지만 실제 타일은 바위로 남음.
- 원인: 예고 좌표에 기절을 먼저 적용한 뒤 바위 생성 시도. 임시 지형이 원래 가구의 바닥/부착 정보를 보존하지 않았고, 지형 쓰기가 거절되어도 성공으로 보고해 복원 실패를 놓침.

원본 수정
- 실제 생성에 성공한 바위 기록에 stunTurns=1을 둠. 실제 바위 칸에 겹친 적만 공통 상태이상 처리로 기절. 빙판·다른 임시 지형·불변 타일 등으로 바위가 생기지 않으면 기절도 없음. 진영·상태 면역 유지.
- 임시 지형 소유자가 원래 바닥/부착 정보를 기록하고 복원. 실제 지형 쓰기 거절은 실패 반환. 복원 실패한 기록은 버리지 않음.
- 바위는 생성 행동 동안 유지하고 다음 실제 행동의 명시적 만료 시각에 붕괴. 복원이 끝난 바위만 한 번 폭발. 복원한 벽들에 가려 붕괴 범위가 잘리는 일 없이 기존 3×3 대지 피해 경로 사용.
- 조수 변화는 임시 지형 아래 원래 가구의 바닥에도 반영. 깊은 물 위 가구 복원을 허용된 원래 부착 정보로 처리.
- 저장 마이그레이션 소유자에서 구형 바위 타이머·복원 정보를 보완하고 타이머 없는 바위 잔류를 복구. 기록이 없는 옛 바위의 원래 가구/바닥은 저장된 용궁 시설·재질·높이 정보에서 복구하며, 정보가 없는 일반 지역은 바닥으로 복구.
- 회복 비약 공통 사용 소유자가 실제 actor.inventory에서 한 개를 꺼내는 데 성공한 뒤 효과 적용. 용왕·플레이어가 같은 경로 사용. 제거된 아이템·수량0·비약이 아닌 아이템은 회복 효과 없음. 플레이어의 이중 소모 제거.
- 광산 돌 공통 투척 소유자가 현재 사거리·막힘·목표와 실제 인벤을 확인한 뒤 한 개 꺼내 기존 투사체·피해·스위치·바닥 아이템 경로 실행. 용왕과 플레이어가 같은 경로 사용.
- 용왕 투척 가능 여부는 실제 돌 수량으로 판단. 예고 시의 가짜 일회성 플래그 제거. 실제 투척 시 지정한 스위치를 다시 확인. 예고 중 돌이 없어지거나 사선이 막히면 소비/투척 없음.
- 인벤 생성·회복량·왕의 회복 조건·돌 피해·사거리·기술 쿨·무적·조수 AI·스프라이트 유지. 사용한 물약은 죽을 때 드롭되지 않으며, 던진 돌은 바닥에 실제 한 개만 남음.
- 신규 wrapper·monkey patch·함수 재대입·런타임 지도 사후 보정 없음. 원본 소유자 직접 수정. 이름 붙은 최상위 함수 추가 없음.

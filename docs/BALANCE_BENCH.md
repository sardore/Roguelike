# 초반 밸런스 벤치 (직업 × 1~3층 몬스터)

`node tests/tools/balance.mjs [판수=12]` (QA 빌드 필요: `npm run build:qa`). 직업마다 새 판을 열고, 1~3층 일반 몬스터를 한 마리씩 방 안에 놓아 단순한 봇(가까우면 때리고, 멀면 다가감/사격)이 싸운다.
- 매 행동 전에 체력을 가득 채워 판이 죽음으로 끝나지 않게 하고, **그 싸움에서 받은 피해 합계**를 잰다. 직업의 실제 최대 체력과 비교한 `죽는 비율`(피해 ≥ 최대 체력)이 핵심 지표다.
- 경험치·레벨·가방(화살)은 싸움마다 원래대로 되돌린다. 아이템·무술·부적·회복·도주는 쓰지 않는다. 시작 장비·시작 레벨 그대로의 기본 전투력이다.
- 160턴 안에 못 잡으면 "못 이김". 시종(원거리 후퇴형)·떠돌이 도둑(기습 후 후퇴)·거대 거미는 봇이 쫓아가다 시간이 다 되는 경우가 많아 승률이 낮게 나온다(봇의 한계). 피해량·죽는 비율은 이긴 판 기준이라 그 경우는 비교하지 말 것.

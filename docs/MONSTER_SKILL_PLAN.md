# 몬스터와 공용 스킬 정의 분리 제안

몬스터 정의에는 종의 스탯, 스프라이트, 보유 스킬 ID, 종별 매개변수와 사용 순서를 둔다. 공용 스킬 정의에는 발동 조건, 예고 데이터, 피해 및 상태이상 처리, 효과 표시와 조사 창 설명을 둔다. 거울지기의 HP 구간별 스킬 순환은 전용 AI가 소유한다.

첫 이관 후보는 이미 여러 종이 공유하는 경종과 피뢰침이다. 기존 호출부를 한 스킬씩 옮기면서 현재 예고 및 해결 경로와 조사 창을 연결한다. 사용처를 모두 옮긴 뒤 기존 구현을 같은 커밋에서 지운다. 기존 저장본에 남아 있는 예고와 재사용 대기 데이터는 동일한 형식으로 해석한다.

한 스킬을 이관할 때마다 일반 전투·디버그 전장·소환 개체의 대상 선정, 예고 해제, 명중 효과와 저장 복원 결과를 기존과 비교한다. 이관 단계에서는 수치와 외형을 그대로 둔다.

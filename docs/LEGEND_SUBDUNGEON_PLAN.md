# 남은 전설던전의 서브던전 이관 계획

전설던전(한 장짜리 맵 + 랜덤 포탈)을 천면경탑처럼 **본관 고정 입구 + 여러 층 + 보스 + 보상**을 가진 서브던전으로 바꾼다. 이 문서는 설계만 담는다(코드 변경 없음).

## 이관 현황

| 전설무기 | 던전 | 상태 |
|---|---|---|
| 창해 수압연노 | 창해 용궁 (본관 9층) | 완료 |
| 귀박 쇄겸 / 황천 저주창 / 진문 파성추 | 흑성채 (본관 16층) | 완료 |
| 천면경 검 | 천면경탑 (본관 14층) | 완료 |
| 적련 불꽃도끼 | 구천낙화 제련성 | 남음 |
| 청뢰 장창 | 뇌정 칠주 수문궁 | 남음 |
| 주박 저주칼 | 혈문 주박사당 | 남음 |
| 지맥 대지수갑 | 천근 붕락권역 | 남음 |
| 적연 용암궁 | 적연협곡 (Z축 서브던전) | 남음 |

## 천면경탑에서 얻은 틀 (그대로 재사용)

1. **등록**: `BRANCH_DEFS105`에 던전 한 항목(`count`, `parent`, `titles`). 본관 입구는 `branchEntrance`의 층 표에 한 줄.
2. **구 전설던전 차단**: `eligible46`, `forcePortal47`, `LegendaryDungeonBuilder.enter/build`에서 해당 id를 제외하고 안내 토스트(용궁·천면경탑과 같은 방식).
3. **생성 파일 분리**: `mirrortower.js` 같은 던전 전용 파일 하나(생성 + 보스 + 보상). 그림이 필요하면 `…art.js`를 따로 두되, **기존 그리기(`drawSharedProp`, 지형, 장판 애니메이션)를 먼저 재사용**한다. 새로 그리는 건 던전을 대표하는 것만.
4. **층 데이터 저장**: `branchWorld105.<id>`(런 단위 계획)와 `branchTerrain105.<id>`(층 단위 배치). 저장·이어하기는 기존 페이지 직렬화가 처리한다.
5. **보스 + 보상**: 보스 정의에 `bossPattern`, 처치 시 `…Defeated`에서 전설무기를 떨어뜨린다. `legendDungeon47`로 구 목록의 적을 재사용한다.
6. **테스트**: `tests/<던전>.mjs`에 층 생성(무작위 30~60개 계획), 층 이동, 보스 흐름, 보상, 적 구성, 이 던전만의 규칙.
7. **렌더 규칙**: 벽은 본관의 음공간 + 세로선 규칙, 조명은 `render.js` 조명 훅, 하늘·배경은 던전별 백드롭 한 함수.

## 공통 규칙 (사용자 요구에서 정리)

- 무작위 생성이어야 한다. 런마다 배치가 달라야 하고, 시드는 런 ID.
- 맵은 단순하거나 텅 비면 안 된다. 곁방, 우회로, 곁길 전리품, 가구 밀도를 설계에 포함한다.
- 고도 표현은 시각 레이어. 이동·충돌·시야는 실제 타일.
- 보스 스킬은 **고정된 주기와 패턴**이며, HP 구간별로 순환표와 빈도가 달라진다. 무작위 선택 금지.
- 적은 구 전설던전 목록 + 어울리는 본관·타 별관 적. 스킬 구현은 공용 스킬로 두고(`docs/MONSTER_SKILL_PLAN.md`), 새 스킬은 몬스터 파일에 따로 박지 않는다.
- 전설무기는 보스 처치 후에만 나온다. 이미 소지·획득한 경우 `claimed47`/`possesses47` 규칙 유지.

## 입구 층 배치

본관의 사용 중인 입구는 2·3·7·9·12·14·16층이고, 전설 포탈은 10·13·15·20·25층에 못 나온다. 구 전설던전의 `minFloor~maxFloor`를 존중하면 다음이 겹치지 않는다.

| 던전 | 허용 범위 | 제안 입구 | 층 수 |
|---|---|---|---|
| 구천낙화 제련성 | 6~14 | 8층 | 3 |
| 뇌정 칠주 수문궁 | 6~14 | 11층 | 3 |
| 혈문 주박사당 | 11~19 | 17층 | 3 |
| 천근 붕락권역 | 11~19 | 18층 | 3 |
| 적연협곡 | 16~24 | 22층 | 3 |

한 층에 입구가 둘 이상 겹치면 안 되므로(`branchEntrance`가 층당 하나), 위 표를 그대로 쓴다. 입구 위치는 천면경탑처럼 고정층 + 층 안 위치는 `candidates` 점수로 정한다.

## 던전별 설계

각 던전은 3층이다. **1층은 진입과 탐색, 2층은 고유 기믹의 중심, 3층은 보스**로 통일하고, 층마다 서로 다른 실루엣을 준다.

### 1. 구천낙화 제련성 (적련 불꽃도끼, 테마 `forge`)

- **정체성**: 거대한 이중 제련로. 용암 수로와 쇳물, 불꽃, 금속 다리.
- **층 구성**: 1층 냉각 회랑(식은 쇳물 바닥, 외곽 순환로) → 2층 제련로(쇳물 수로와 압연 발판, 식힘/달굼 스위치) → 3층 용광 정상(보스).
- **고유 기믹**: **쇳물 수위**. 일정 주기로 용암이 차오르고 빠진다. 차오른 구간은 임시 용암으로 바뀌고, 이동 발판(천면경탑 발판 이동기 `movePlatform57` 재사용)으로만 건넌다.
- **적**: 용철 화로지기, 불씨 식귀, 제련 도깨비(구 목록) + 본관의 살라맨더, 화염 가고일.
- **보스**: 제련장 `화로의 주인`. 고정 순환표: 열기 폭발(예고 2턴) → 쇳물 낙화(8방향 불바닥, 기존 불바닥 필드) → 불씨 소환. HP 낮을수록 낙화 빈도가 늘고 수위 주기가 짧아진다.
- **그래픽**: 붉은 쇳물·주황 빛·검은 철골. 벽은 검붉은 철판 단면, 바닥은 달궈진 판, 대표 가구는 풀무·모루·도가니(여러 타일).
- **주의**: 불꽃도끼 소유 시 화염 면역 규칙(`guard47`)과 용암 수로 규칙이 충돌하지 않는지 확인.

### 2. 뇌정 칠주 수문궁 (청뢰 장창, 테마 `storm`)

- **정체성**: 번개 기둥 일곱 개가 선 물 위 궁전. 수문과 도체.
- **층 구성**: 1층 수문 광장(물길과 도체 바닥) → 2층 칠주 회랑(기둥 점등 퍼즐) → 3층 뇌정전(보스).
- **고유 기믹**: **칠주 점등**. 기둥 일곱 개를 순서대로 켜면 길이 열리고, 틀리면 낙뢰. 낙뢰 칸 예고는 기존 피뢰침(`startLightningRod`/`'rod'`) 재사용.
- **적**: 뇌우 사수, 피뢰 갑병, 전도 정령(구 목록) + 본관 금령, 공허 가오리.
- **보스**: 뇌정의 주인. 순환표: 낙뢰(피뢰침 3연타) → 기둥 충전(안전 칸 예고) → 전도(물 위 감전 확산). HP 구간마다 기둥이 하나씩 더 활성화된다.
- **그래픽**: 청백 번개빛과 짙은 청회색 석재. 물과 기둥이 많아 천면경탑의 물 렌더(`drawGlassLake` 같은 백드롭 함수)를 일반화해 쓸 수 있는지 먼저 검토.
- **주의**: 청뢰 장창 낙뢰 연쇄(`thunderPulse`)와 감전 확산 규칙 충돌 확인.

### 3. 혈문 주박사당 (주박 저주칼, 테마 `curse`)

- **정체성**: 금기와 혈인이 새겨진 사당. 저주와 봉인.
- **층 구성**: 1층 사당 앞마당(금줄, 봉인문) → 2층 혈문 회랑(봉인 방 여러 개, 열쇠 대신 저주 조건) → 3층 본당(보스).
- **고유 기믹**: **금줄 봉인**. 문마다 조건(HP 일정 이하, 저주 장비 착용 등)이 걸려 있고, 어기면 주박 상태이상. 주박 저주칼의 "저주 장비 수에 비례한 강화"와 연결된다.
- **적**: 주박 검객, 사당 주술시종, 혈인 원혼(구 목록) + 본관의 꿰맨 입 망자, 어둑시니.
- **보스**: 혈문의 사제. 순환표: 봉인진(범위 예고 후 기봉인) → 혈인 낙인(표적 지정 `targetMark61` 재사용) → 원혼 소환. HP가 낮을수록 봉인진이 겹쳐 깔린다.
- **그래픽**: 어두운 적갈색, 붉은 인장과 금줄, 낡은 나무와 먹. 대표 가구는 위패 단, 금줄 기둥, 인장석.
- **주의**: 주박 저주칼 소유 시 최대 HP -50% 규칙과 사당 안 저주 판정이 중복 적용되지 않게.

### 4. 천근 붕락권역 (지맥 대지수갑, 테마 `quarry`)

- **정체성**: 무너지는 채석장 권역. 균열, 낙석, 지맥.
- **층 구성**: 1층 채석 입구(바위 길, 흔들리는 다리) → 2층 붕락 구간(밟으면 무너지는 칸, 단단한 바위 길 찾기) → 3층 지맥 심부(보스).
- **고유 기믹**: **붕락 바닥**. 기존 `CRUMBLE` 타일과 `armFragile` 규칙 재사용. 지맥 스택을 쌓으면 안전한 바닥이 생기도록 대지수갑 능력과 연동.
- **적**: 석분 권사, 붕락 갑병, 토맥 괴수(구 목록) + 본관 정원 바위괴물, 만루의 수호상.
- **보스**: 지맥의 거인. 순환표: 지진(성벽 강타 `wallSlamTurn` 재사용) → 낙석(예고 2턴) → 균열(일직선 붕락). HP 구간마다 안전 칸이 줄어든다.
- **그래픽**: 황토·회갈색 암석 단면, 균열 틈의 지맥 빛. 낮은 단과 깊은 구덩이로 고도 표현이 중심.
- **주의**: 붕락 바닥이 이동 경로를 영구히 끊지 않도록 도달 가능성 검사에 "붕락 후 대체 경로" 항목을 넣는다.

### 5. 적연협곡 (적연 용암궁, 테마 `range`) — 2026-11-21 변경: 화구사대 → Z축 협곡

- **정체성**: 붉은 연기가 깔린 깊은 협곡. 위에서 쏘고 아래에서 불타는, **높이가 규칙인 던전**. 용암궁의 "용암 장례(시체 주변 3×3 임시 용암)"가 **아래로 흐르는** 불이 된다.
- **Z축의 정의**: 다른 던전의 고도는 시각 레이어(이동·충돌·시야는 실제 타일)지만, 이 던전만 **높이가 규칙**이다. 이 예외를 문서의 공통 규칙에 한 줄로 적고, 협곡 던전 안에서만 켠다.

#### Z축 구현안 두 가지

| | A. 층쌓기형 (권장 시작점) | B. 층 안 Z형 |
|---|---|---|
| 방식 | 3개 층이 **같은 협곡 외형**(같은 지형 시드)을 공유한다. 상단 림 → 중단 벼랑길 → 바닥 용암 강. 위층의 벼랑 끝 칸은 허공이고, 뛰어내리면 **같은 x,y**의 아래층에 떨어진다. | 한 층 맵의 칸마다 높이 0~3을 둔다. 경사로·사다리 칸만 높이를 오르내리고, 높이 차 2 이상은 막히거나 낙하. |
| 엔진 변경 | 거의 없음. 층 이동·저장은 기존 서브던전 틀. 낙하 = "같은 좌표로 층 이동 + 피해". | 도달성·시야·사거리·배치 서비스에 `z` 판정이 들어간다. 크다. |
| 위험 | 위·아래층이 같은 지형이어야 해서 생성기가 한 번에 세 층을 만든다. | 저장 형식·시야 계산·AI 길찾기 전부 영향. |

권장: **A로 먼저 만들고**, 재미가 확인되면 B의 일부(사선 높이 보너스)만 따로 올린다.

#### 층 구성 (A안)

1. **1층 상단 림**: 협곡 가장자리 길. 넓은 사선 지형과 엄폐물(바위·방열판), 벼랑 끝에서 아래를 내려다보는 사격. 곳곳에 **낙하 지점**(뛰어내리면 3층의 용암 강변으로 바로 감: 지름길이지만 피해 + 퇴로 없음).
2. **2층 중단 벼랑길**: 절벽에 붙은 좁은 선반길, 매달린 다리, **수직 승강대**(기존 발판 이동기 `movePlatform57`을 위아래 층 사이로 오가는 승강기로 확장). 위층 적이 위에서 쏘고, 아래 용암에서 불꽃이 튄다.
3. **3층 바닥 용암 강**: 용암 강과 현무암 섬, 적연(붉은 연기) 가득. 보스 방은 협곡 맨 아래 분화 구멍.

#### 고유 규칙

- **고저 사격**: 위에서 아래로 쏘면 사거리 +1이고 엄폐를 무시한다. 아래에서 위로는 절벽 면이 시야를 막아 벼랑 끝 칸 근처에서만 보인다. (A안에서는 "위층 허공 칸에서 아래층을 쏜다"로 처리.)
- **용암은 아래로 흐른다**: 용암 장례로 생긴 임시 용암이 벼랑 끝에서 아래층 같은 칸으로 **떨어져** 거기에 임시 용암을 만든다. 위에서 처치하면 아래층의 아군·적이 불탄다. 자기 발밑 아래를 태우지 않도록 퇴로를 읽어야 한다.
- **적연(붉은 연기)**: 연기는 위로 퍼져 **바닥층일수록 짙다**. 기존 연기 장(`smoke`)은 소음을 막으므로(`alertNearby`), 짙은 구간은 은신과 소음 차단이 된다. 반대로 시야도 줄어 사선이 짧아진다.
- **낙하**: 벼랑에서 일부러 뛰어내려 층을 건너뛴다. 피해 `3 + 층차`, 낙하 직후 1턴 행동 불능 대신 착지 지점 적의 공격이 확정 명중이 되지 않도록 첫 발견 확정회피 규칙을 따른다. 되돌아가는 길은 사다리·승강대뿐이다.
- **협곡 열기**: 바닥층은 일정 턴마다 용암이 한 칸씩 수위를 올린다(고정 주기, 무작위 금지). 승강대·섬 위에서 버티지 못하면 위층으로 올라가야 한다.

#### 곁방·곁길 (비어 보이지 않게)

- 절벽 속 광맥 방(보상 상자), 매달린 쇠사슬 다리 곁길, 용암 위 현무암 디딤돌 우회로, 승강대 곁 보급 선반. 층마다 가구 밀도를 정해 둔다.

#### 적

- 월화 궁수(림), 재의 감시자(경종 `soundAlarmBell`), 용암 살라맨더(구 목록) + 본관 대포, 경비 인형 포병. **날개 달린 적(금령, 화염 가고일)**은 층 경계를 넘나드는 위협이다. 새 스킬은 몬스터 파일에 박지 않고 공용 스킬로 둔다.

#### 보스: 협곡의 주인 (적연 지룡, 가칭)

- 3층 분화 구멍에서 싸운다. **HP 구간마다 용암 수위가 한 층 올라** 발밑 선반이 하나씩 잠긴다(고정 순환표).
- 순환표: 화구 연사(직선 예고) → 경종(졸개 괴력) → 지대 포격(8방향 불바닥). 구간이 오를수록 포격 칸수와 수위 상승 주기가 짧아진다.
- 전설무기 용암궁은 보스 처치 후에만 나온다.

#### 주의

- 용암궁 소지자는 용암 면역이 아니므로 낙하·용암 흐름으로 자기 퇴로를 태울 수 있음을 입구에서 안내한다.
- 위·아래층 지형을 공유하므로 **어느 층에서도 시작→출구 도달 검사**와, 낙하 후 **되돌아올 수 없는 구간이 출구를 막지 않는지** 검사한다.
- 고도 그림은 계획된 공용 `cliffart.js`(벼랑 면과 아래 장식)를 쓰고, 협곡 전용으로 따로 그리지 않는다.
- 적 구성과 입구 층(22층)은 앞 표를 따른다.

## 작업 순서 제안

1. **청뢰 장창 → 구천낙화** (이미 있는 피뢰침·불바닥·발판 재사용이 가장 많음)
2. **주박 저주칼** (봉인진·표적 지정 재사용)
3. **천근 붕락권역** (붕락 기믹은 새 규칙이 필요해 중간에 둠)
4. **적연협곡** (용암 규칙이 앞의 두 던전과 겹치고 Z축 규칙이 새로 필요해 마지막)

던전 하나마다: 설계 확정 → 생성 + 테스트 → 그래픽 → 보스 → 전체 회귀 → 병합. 한 던전씩 병합해 서로 충돌하지 않게 한다.

## 공용으로 먼저 정리할 것

- `branchEntrance`의 층 표(`{2:'canal',…}`)와 구 전설던전 차단 코드를 **데이터 한 곳**으로 모으기. 던전을 추가할 때마다 세 군데를 고치는 지금 방식은 실수하기 쉽다.
- 던전별 **백드롭 함수 인터페이스**(하늘·호수·쇳물·바위 등)를 `render.js`에 한 곳으로 모으기. 천면경탑은 `drawGlassSky`를 직접 부른다.
- 던전 생성 테스트의 공통 틀(`tests/mirror-tower.mjs`의 계획 N개 생성 검사)을 함수로 빼기.
- 보스 순환표를 **데이터**(`{hp구간, 스킬, 간격}`)로 표현해, 보스마다 `handleBossPattern` 분기를 새로 쓰지 않기. 몬스터·스킬 분리 계획(`docs/MONSTER_SKILL_PLAN.md`)과 같은 방향.

## 위험과 결정할 것

- **진행 중인 전설던전 런**: 이미 구 전설던전에 들어가 있는 저장은 구 맵 그대로 끝까지 하게 두고, 새로 만드는 입구부터 서브던전으로 잇는다(천면경탑과 같은 방식). 이미 열린 구 포탈이 층에 남은 저장은 보정 로직이 필요하다.
- **전설무기 획득 이력**: `claimed47`·`artifactHistory46`에 이 던전의 기록이 남은 저장이 서브던전 입구를 만들지 않도록 확인.
- **밸런스**: 층 배율은 `branchCombatFloor`가 입구 층 + 층 번호로 계산한다. 입구가 구 `minFloor`보다 낮으면 적이 약해 보일 수 있다. 입구 층을 제안대로 정하되 시뮬레이션으로 확인.
- **전체 회귀의 한계**: 지금 환경에서는 `tests/run.mjs`가 기준선 대비 약 200개 차이를 내서 새 차이를 눈으로 가려야 한다. CI 환경에서 기준선을 갱신해 두면 이후 작업이 쉬워진다.

## 사용자 확인이 필요한 질문

1. 입구 층 제안(8·11·17·18·22)을 그대로 쓸지, 던전마다 다른 층을 원하는지.
2. 던전마다 3층이 맞는지, 큰 던전(제련성·수문궁)은 4층으로 늘릴지.
3. 천면경탑처럼 던전마다 **고유 보스**를 두는 것이 맞는지.
4. 진행 순서(청뢰 장창 먼저)가 맞는지.
